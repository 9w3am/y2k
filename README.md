# Y2K — 두 개의 사이트

한 폴더 안에 서로 다른 사이트 두 개가 들어 있고, 한 번에 같이 배포합니다.

- 첫 화면: https://9w3am.github.io/y2k/
- 아이로그: https://9w3am.github.io/y2k/ilog/
- 수신함: https://9w3am.github.io/y2k/inbox/

```
미니/
  수신함   ← 문자메이커/   폰·PC 화면을 만들어 PNG로 뽑는 도구
  아이로그 ← 미니홈피/     미니홈피 서비스 (가입·로그인, 웹 + 프로그램 모드 + 설치형 웹앱)
  landing/                첫 화면과 404
  supabase/               아이로그 서버 표·규칙 (Supabase 에서 한 번 실행)
  tools/
    brand.mjs             파비콘·링크 미리보기 그림 (SVG → 크롬으로 PNG)
    shots.mjs             실제 화면 고해상도로 찍기 (크롬 헤드리스)
    og.mjs                찍은 화면으로 미리보기 만들기 (시험용)
    make-icons.mjs        예전 앱 아이콘 생성기
```

## 어디서든 열립니다

폰·태블릿·PC 모두 대응합니다. 좁아지면 세로로 쌓이고, 손가락으로 누르는 기기에서는
조작점이 커집니다. 수신함 캔버스는 어느 크기에서든 통째로 축소될 뿐 안쪽이 재배치되지 않습니다.

## 돌려보기

```bash
npm --prefix ./문자메이커 run dev
```

```bash
npm --prefix ./미니홈피 run dev
```

## 배포

`.github/workflows/deploy.yml` 이 `main` 에 올릴 때마다 두 사이트를 빌드해 한 폴더로 모으고
GitHub Pages 로 내보냅니다.

```
/            Y2K — 두 사이트 고르는 첫 화면
/ilog/       아이로그
/inbox/      수신함
```

- 링크 미리보기 주소(`og:url`·`og:image`)는 index.html 에 `__SITE__` 로 두고 배포 때 계정 이름으로 채웁니다.
  404 페이지 링크는 `__BASE__`. 그래서 깃허브 아이디나 저장소 이름을 바꿔도 다시 배포만 하면 맞춰집니다.
- 아이디를 바꿨다면 Supabase → Authentication → URL Configuration 에 새 주소를 넣어야
  가입 인증·비밀번호 재설정 링크가 새 주소로 돌아옵니다.
- 두 사이트 모두 `manifest.webmanifest` 와 서비스 워커가 있어서, 배포한 주소를 브라우저에서 열면
  **설치**해 프로그램처럼 쓸 수 있습니다. 서비스 워커는 페이지를 늘 새로 받아와서 옛 화면이 남지 않습니다.

### 파비콘·미리보기 다시 그리기

```bash
node tools/brand.mjs sheet 후보폴더
```

```bash
node tools/brand.mjs final 임시폴더 y2k=Y2 ilog=I2 inbox=S2 og=P5
```

`final` 은 `landing/`, `미니홈피/public/`, `문자메이커/public/` 에 favicon.svg · favicon-32 · apple-touch-icon ·
icon-192/512 · og.png 를 씁니다. 지금 쓰는 것은 반짝 구슬(Y2) · 하트 i(I2) · 폴더폰(S2), 미리보기는 도트(P5).

### 내 도메인 붙이기

도메인은 따로 사야 합니다. 호스팅 값은 Pages 가 공짜라 0원입니다.

1. 도메인 판매처에서 도메인을 산다
2. DNS 에 레코드를 넣는다
   - `example.com` — `A` 레코드 네 개: `185.199.108.153` `185.199.109.153` `185.199.110.153` `185.199.111.153`
   - `www.example.com` — `CNAME` 레코드 하나: `9w3am.github.io`
3. 저장소 → **Settings → Pages → Custom domain** 에 도메인을 넣고 저장
4. 인증서가 발급되면 **Enforce HTTPS** 를 켠다

도메인을 붙이면 워크플로의 주소 채우기(`__SITE__`)도 그 도메인으로 바꿔야 합니다.

## 수신함

폰·PC 화면을 띄워놓고 **화면 속 글자를 직접 눌러 고친 뒤** PNG로 저장합니다.

테마 6종: 문자 쓰기 / 문자 보기 / 메시지 작성 / 편지지·아바타 / 받은문자함 / PC 문자 발송기

- 고정 픽셀 캔버스. 창을 줄이면 화면 전체가 축소될 뿐 내부는 재배치되지 않습니다.
- 아이콘은 전부 SVG로 도트를 직접 찍었습니다.
- 실제 통신사 로고는 들어 있지 않습니다. 사용자가 고칠 수 있는 글자입니다.
- 글꼴은 직접 들고 있습니다. 바깥 CSS 를 읽으려다 PNG 저장이 오래 걸리던 문제를 없앴습니다.
- **화면 효과 층**(`src/editable/ScreenFx.tsx`) — 색조·서브픽셀 결·유리 반사·가장자리 그늘·초점 흐림.
- 만든 내용은 이 브라우저 안에만 저장됩니다.

테마 추가: `src/themes/{id}/` 폴더(`index.tsx` · `theme.css` · `defaults.ts`)를 만들고
`src/themes/registry.ts` 에 한 줄 더합니다.

## 아이로그

미니홈피 서비스를 통째로 되살린 사이트입니다. 로그인 화면부터 상점까지 실제로 돌아갑니다.

| 예전 | 아이로그 |
|---|---|
| 도토리 | **잉크** (글·사진을 올리면 한 방울씩 모임) |
| 일촌 | **단짝** |
| 파도타기 | **로그타기** |
| 미니룸 | **내방** |

### 되는 것

- **가입·로그인** (이메일 + 아이디). 로그인하면 기록장과 사진이 서버에 저장되고, 다른 기기에서도 이어집니다.
  가입 없이도 이 브라우저 안에서 쓸 수 있습니다.
- **아이디로 놀러가기** — `#/u/아이디` 로 남의 기록장 구경
- **진짜 단짝** — 아이디로 신청 → 상대가 수락. 로그타기는 실제 단짝의 기록장으로
- **방명록** — 로그인해서 남김. 비밀글은 주인과 쓴 사람만 볼 수 있게 서버 규칙이 막음
- 블로그처럼 쓰는 다이어리·게시판·페이퍼 (카테고리, 사진, 공감, 댓글)
- 사진첩, 상점 스킨, 꾸밈새, TODAY/TOTAL 카운터, 화면에서 바로 고치기
- **PNG 저장** — 보이는 그대로, 웹/프로그램 모드 각각
- **웹사이트 모드 ↔ 프로그램 모드** 전환
- BGM 플레이어 (브라우저가 직접 연주하는 곡 + 유튜브·음악 파일)

### 서버 (Supabase)

`supabase/setup.sql` → `supabase/setup-2-friends-guestbook.sql` 순서로 한 번 실행합니다.

- `homes` — 사람마다 기록장 한 벌 (누구나 읽고, 본인만 고침). 방명록·단짝은 여기 넣지 않습니다.
- `friends` — 단짝 신청·수락
- `guestbook` — 방명록 (비밀글은 주인·쓴 사람만 읽음)
- `photos` 보관함 — 본인 폴더에만 올림
