# 그 시절 — 두 개의 사이트

한 폴더 안에 서로 다른 사이트 두 개가 들어 있습니다. 각자 독립적으로 돌아가고,
따로 배포합니다.

```
미니/
  수신함  ← 문자메이커/   그 시절 폰·PC 화면을 만들어 PNG로 뽑는 도구
  아이로그 ← 미니홈피/     2000년대 미니홈피 서비스 (웹 + 프로그램 모드 + 설치형 웹앱)
  tools/make-icons.mjs    앱 아이콘 생성기 (의존성 없음)
```

## 어디서든 열립니다

폰·태블릿·PC 모두 대응합니다. 좁아지면 세로로 쌓이고, 손가락으로 누르는 기기에서는
조작점이 커집니다. 캔버스는 어느 크기에서든 통째로 축소될 뿐 안쪽이 재배치되지 않습니다.

## 돌려보기

```bash
npm --prefix ./문자메이커 run dev
```

```bash
npm --prefix ./미니홈피 run dev
```

## 배포

둘 다 정적 사이트라 GitHub Pages·Netlify·Vercel 어디든 올라갑니다.
`base: './'` 와 해시 라우팅을 쓰기 때문에 하위 경로(`/user/repo/`)에 올려도 그대로 동작합니다.

```bash
npm --prefix ./문자메이커 run build   # → 문자메이커/dist
```

```bash
npm --prefix ./미니홈피 run build     # → 미니홈피/dist
```

두 사이트 모두 `manifest.webmanifest` 와 서비스 워커가 있어서, 배포한 주소를
브라우저에서 열면 **설치**해 프로그램처럼 쓸 수 있습니다. (HTTPS 필요)

## 수신함 — 그 시절 화면을 그대로

폰·PC 화면을 띄워놓고 **화면 속 글자를 직접 눌러 고친 뒤** PNG로 저장합니다.
따로 입력 폼을 찾을 필요가 없습니다.

테마 6종: 문자 쓰기 / 문자 보기 / 메시지 작성 / 편지지·아바타 / 받은문자함 / PC 문자 발송기

### 디자인 원칙

- 고정 픽셀 캔버스. 창을 줄이면 화면 전체가 축소될 뿐 내부는 재배치되지 않습니다.
- 아이콘은 전부 SVG로 도트를 직접 찍었습니다. 현대 아이콘 세트를 쓰지 않습니다.
- 실제 통신사 로고는 들어 있지 않습니다. 조판만 흉내 낸 글자이고 사용자가 고칠 수 있습니다.
- 글꼴은 CDN 이 아니라 직접 들고 있습니다(두 사이트 모두). 바깥 CSS 를 읽으려다 PNG 저장이 10초 넘게 걸리던 문제를 없앴습니다.
- 화면 모서리는 둥근 것이 기본이고 각진 것도 고를 수 있습니다. 저장할 때 모서리를 직접 잘라내므로 PNG 모서리가 깔끔하게 떨어집니다.
- **화면 효과 층**(`src/editable/ScreenFx.tsx`)이 핵심입니다. 색조·서브픽셀 결·유리 반사·
  가장자리 그늘·초점 흐림을 얹어 '찍은 사진'처럼 보이게 합니다. 이게 없으면 아무리 잘
  그려도 요즘 목업처럼 보입니다.

### 테마 추가하기

`src/themes/{id}/` 폴더(`index.tsx` · `theme.css` · `defaults.ts`)를 만들고
`src/themes/registry.ts` 에 한 줄 더합니다. 공용 코드에 테마 분기를 넣지 않습니다.

## 아이로그 iLOG — 오늘의 나를 기록하는 곳

2000년대 미니홈피 서비스를 통째로 되살린 사이트입니다. 화면 한 장이 아니라
로그인 화면부터 상점까지 실제로 돌아갑니다.

| 그 시절 | 아이로그 |
|---|---|
| 도토리 | **잉크** (글·사진을 올리면 한 방울씩 모임) |
| 일촌 | **단짝** |
| 파도타기 | **로그타기** |
| 미니룸 | **내방** |

### 되는 것

- 다이어리·게시판·페이퍼 글쓰기/삭제, 기분·날씨 고르기
- 사진첩 업로드, 방명록 작성·답글·비밀글, 단짝네 놀러가기
- 상점에서 스킨 구입(잉크 차감) 및 즉시 적용, 스킨 6종 (맑은 하늘·벚꽃·레몬사탕·체크노트·밤하늘 별자리·블랙민트)
- TODAY/TOTAL 방문 카운터 (날짜가 바뀌면 TODAY 는 1부터)
- 프로필·자기소개·기록장 이름을 화면에서 바로 눌러 수정
- 백업 파일(.json) 내려받기
- **PNG 저장** — 보이는 그대로, 스킨 바탕과 무늬까지 3배 해상도로
- **웹사이트 모드 ↔ 프로그램 모드** 전환 (창·메뉴바·작업표시줄·시작메뉴)
- BGM 플레이어 — 이전/다음 곡, 재생·일시정지, 재생 위치 막대(눌러서 이동), 음량

### BGM

`src/lib/bgm.ts` 에서 **브라우저가 직접 연주**합니다. 음원 파일이 없습니다.
오르골·피아노 음색을 Web Audio 로 만들고, 멜로디 4곡은 손으로 적었습니다.
멈출 때는 예약을 끊는 것만으로 부족해서 울리던 소리까지 전부 끊습니다 —
그러지 않으면 다시 켤 때 한꺼번에 쏟아집니다.
무작위 생성은 반드시 이상하게 들리기 때문에 쓰지 않았습니다.

### 나중에 여러 사람이 같이 쓰려면

`src/lib/storage.ts` 의 `Driver` 를 구현한 원격 드라이버를 만들고
`setDriver()` 로 갈아끼우면 됩니다. 나머지 코드는 손대지 않습니다.

## 배포용으로 비워둔 것

아이로그의 이름·자기소개·다이어리·방명록·단짝은 전부 '견본' 문구입니다.
공유해도 부끄럽지 않도록 특정 인물을 만들어 넣지 않았습니다.

## 만들 때 지킨 것

- 현대 UI 라이브러리·아이콘 세트·부드러운 등장 애니메이션을 쓰지 않습니다.
- 픽셀 글꼴은 정수 배율(11/22px)로만 씁니다.
- 실제 기업 로고를 복제하지 않습니다.
- 올린 사진과 글은 브라우저 안에만 저장되며 어디로도 전송되지 않습니다.
